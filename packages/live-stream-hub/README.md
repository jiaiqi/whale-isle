## 职责（直播大脑、注意力调度与高光切片）

- **事件归一**：以 `dyhub` 为抖音弹幕主线（不采用浏览器方案），B 站/本地宿主输入归一为 `NormalizedLiveEventSchema`；同观众短时弹幕合并、礼物连击合并。
- **三级注意力队列（Attention Arbiter）**：
  - **P0 即时抢占**：主人接管、雷区反射、高价值礼物（投喂红烧肉）、星露谷濒危。
  - **P1 节拍器（4~6 秒一拍）**：点歌演唱、合并弹幕问答、弹幕议会（20s 投票）、任务汇报。
  - **P2 空闲填补**：进房欢迎（查常客账本翻旧账）、内心戏碎碎念、节目状态切换。
- **节目状态机**：`GAMING_MAIN ↔ SINGING_CONCERT ↔ CHATTING_INTERACT ↔ SLEEP_OFF_DUTY` 防呆切换，杜绝画面冷场发呆。
- **防封护栏**：三道敏感词护栏 + 输入清洗（`sanitizedText`）。
- **高光/翻车切片**：45s 环形缓存；"矿洞晕倒 / 炸农田 / 哈哈哈哈密度激增"自动打点，下播后调视觉模型生成毒舌复盘字幕草稿（受每日视觉预算上限控制；视觉严禁参与实时游戏控制）。
