> **T-M6-27（P0，正确性）多游戏/多端点事件与指令隔离**
>
> **问题**：单例 autodrive（`autodrive-host.ts`）与联机 agent 池（`coop-host.ts`）向同一 `autodrive:event` 通道发送事件；单例事件没有 `agentId` / `sessionId` / `generation`，渲染层 `App.tsx` 订阅后统一放入一个 `events` 数组，未按当前游戏或端点过滤。当前游戏、顶栏运行状态、回执时间线、DST 面板与 pet-stage 都可能消费不属于本会话的事件；切换游戏清空数组只能掩盖旧 runner 的迟到事件。**结果**：星露谷页可能显示泰拉瑞亚动作；一个桌宠启动后另一个端点面板也显示「自动驾驶中」；快捷指令可能发给 UI 当前选择之外的游戏。
