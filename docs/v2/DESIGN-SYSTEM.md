# Whale Isle V2 — 曜潮设计规范（Obsidian Tide Design System）

> **设计资产源**：`design/v2-gemini/`（Obsidian Tide 16 文件）· `whale-isle-v2-obsidian.html` · `design/`（Obsidian v4 运行基线）  
> **决议依据**：[ADR-001](./adr/ADR-001-v2-foundation.md)（第一轮审查批准：继承设计基因演进，**不将「六世界 × 十页面」锁定为不可调整的硬限制**）

---

## 一、核心视觉语言与主题系统

1. **主题机制**：继承 Obsidian v4 的极客精密感与 Tide v5 的深海屿光情绪，提供三态主题切换（默认 **`data-theme="system"`** 自动跟随操作系统浅深色）：
   - **曜石深海（Dark）**：纯曜石黑底 `#050507` 叠加五层半透明玻璃材质与鲸光青 `#3EE0CD` / 系统蓝 `#0a84ff` 强调色。
   - **晨汐瓷白（Light）**：高可读暖冷平衡瓷白表层，适配白天长时办公与游戏协同阅读。
2. **五层材质层级**：从底壳层（Canvas）、导航岛层（Strata Rail）、工作卡片层（Surface）、浮层（Popover / `⌘K`）到关键状态光晕层（Sonar / HUD），保持明确的层级对比与 `backdrop-filter` 克制使用。
3. **绝对工程约束**：
   - **零外网 CDN 图标依赖**：所有图标统一由本地 `lucide-react` / 离线图标包渲染，**禁止正文/按钮中使用彩色 Emoji 充当系统图标**。
   - **零虚假指标**：严禁像反面样本那样渲染假码率、假观众数或编造余额；未接入后端或不可查询项必须显式展示「未接线 / 未知 / 不可查询」。

## 二、统一角色锚点与多表面硬件边界

1. **单一主角色锚点**：全局视觉与监控数据严格锚定主角色 **小鲸（`char_xiaojing` / 原型代号 `char_wh001`）**，被动伴侣使用独立弱存在感标识，杜绝不同页面出现互相冲突的角色人设。
2. **三大独立渲染表面**：
   - **中控台（`director`）**：负责身份、生命状态、记忆图谱、创作工坊、供应商矩阵、安全治理与研发看板；左侧导航 + 右侧按需 `GET_STATE` 实时监视侧栏。
   - **透明桌宠窗（`pet-stage`）**：独立无边框置顶透明窗，负责 WebM / Spritesheet（预留 Live2D / VRM）动画、鼠标像素级穿透（`ignoreMouseEvents`）、拖拽反馈、紫色虚线 `<think>` 气泡与 0-token 快速反应，**不强行嵌死在中控台内部**。
   - **托盘浮窗（`tray-popover`）**：独立 344px 菜单栏快捷浮窗，负责即时心情、Token 饭碗余额、AI/玩家控制权瞬切、静音与睡眠安静模式。

## 三、四大签名组件与全局快捷键

### 四大核心签名组件
1. **声呐环（Sonar Ring）**：统一投射小鲸的 9 态即时生命/呼吸/专注/思考/演奏状态，保证桌面态与中控台同频。
2. **四态回执芯片（Receipt Chip）**：严格区分 `PENDING` / `COMPLETED` / `FAILED` / `UNCERTAIN`，拒绝只写「完成」的误导性提示；游戏与工具调用必须展示真实回执状态。
3. **许可徽章（License Badge）**：直观标出 `MIT` / `Apache-2.0` / `DEV_ONLY_NON_COMMERCIAL`（如 CrossPet、内置大肥鱼 WebM）授权等级，高风险操作或商用发布前强制视觉警示。
4. **控制权 HUD（Control Ownership HUD）**：置顶常驻显示当前设备级 `ComputerUseLease`、游戏角色级 `GameCharacterControlLease` 与活动级 `LifeActivityAuthority` 归属，提供一键物理接管按钮。

### 全局快捷键契约
- **`⌘K` / `Ctrl+K`**：全局快速跳转、能力检索与命令面板。
- **`F8`**：P0 紧急停手，立即中止在飞动作并将全部游戏/自动化控制权退回人类用户。
- **`F9`**：在 AI 自主托管与玩家掌控之间一键切换控制租约。
- **`F10`**：切换小鲸「睡眠安静模式」，暂停主动发声与打扰。

## 四、IA 演进与 Strangler 重构路径（`V2-P1-05`）

- 推荐按六个功能域组织信息架构：伴侣与身份、数字生活与记忆、游戏舞台与协玩、创作与资产工坊、平台模型与扩展生态、安全治理与自主研发；实际导航结构随模块真实可用度渐进上线，不强制一次空壳铺满十个未接线页面。
- 重构目标是以模块化领域组件逐步替代目前 `apps/desktop-host/src/renderer/director/App.tsx`（1,466 行）及 `pet-stage/main.ts`（1,686 行），所有控制按钮须直连真实主进程内核 IPC（含 `V2-P0-02` 已落地的急停与状态接口）。
