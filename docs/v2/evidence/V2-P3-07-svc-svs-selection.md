## 1. 选型结论（先给直话）

**SVC 只剩一个许可干净的选项：RVC（MIT）。** 其余两条主流路线在本仓库的许可证红线（AGENTS §2.2：严禁 GPL/AGPL 传染）下直接出局：

| 候选 | 代码许可（本轮实读） | 判定 | 依据 |
| --- | --- | --- | --- |
| **RVC**（Retrieval-based-Voice-Conversion-WebUI） | **MIT**（代码） | ✅ **唯一可进的 SVC 代码**；底模权重不可商用 | 代码 <https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/blob/main/LICENSE>；权重条款见 O5 逐文件篇 |
| **Seed-VC** | **GPL-3.0** | ❌ 禁止 vendor / 链接进产品 | <https://github.com/Plachtaa/Seed-VC/blob/main/LICENSE> |
| **so-vits-svc** | **AGPL-3.0**（仓库已归档） | ❌ 禁止（AGPL 比 GPL 更严） | <https://github.com/svc-develop-team/so-vits-svc/blob/main/LICENSE> |
| **DDSP-SVC** | MIT（代码） | ⚠️ 备选；默认声码器 CC BY-NC-SA 4.0 不可商用 | 见 O5 候选对比 |
| **GPT-SoVITS** | MIT（代码） | ⚠️ 仅开发期基线，且**是 TTS 不是 SVS/SVC** | 既有结论不变 |
| **Fish Speech** | Fish Audio 社区许可 | ❌ 商用受限 | 见速评 §2.1 原文摘录 |
| **DiffSinger**（SVS） | **Apache-2.0** | ✅ 长期 SVS 主线；官方 OpenCpop 检查点与 OpenVPI 声码器权重非商用 → 商用须自训 | <https://github.com/openvpi/DiffSinger/blob/main/LICENSE> |
| **OpenUtau**（SVS 编排/渲染） | **MIT** | ✅ 可作 SVS 前端（macOS arm64 有官方包） | 见 O5 §1 / 来源；本轮未复核 |
| **NNSVS / ENUNU** | MIT（代码） | ⚠️ 无官方预训练权重，需自训 | 备选 |

**三条写死的红线**：

1. **RVC `.pth` 必须来源可追溯**：只允许 owner 提供授权素材训练出的模型，或 owner 书面授权的模型；模型文件本体与训练配方一起留档（谁的声音、什么授权、训练日期）。**不接受任何来源不明的 `.pth`（包括社区分享的"小萝莉音色"）**。
2. **禁止使用任何歌手/他人的录音**训练或当参考音；儿童声线必须由 owner 取得监护人授权后提供素材，否则只能走「成年授权声源 + 音高/共振峰调整」并如实标注为「合成儿童化」。
3. **SVC ≠ 角色演唱**：RVC 只交付「音色」，演唱风格来自 Singing Profile（SVS 或人工演唱的乐句表达）；点歌台验收按「角色自己的 Singing Profile 真唱」口径，不接受「别人唱完换个音色」。

**为什么先 SVC 后 SVS**（沿用 ADR-005，不重开讨论）：SVC 只需一组合法干声即可产出可用音色；SVS 还需要乐谱/音素对齐与声库训练，链路长、验收慢。阶段一目标是一个完整角色跑通，SVC 是短路径。

**与替代引擎速评的关系**：速评已证明本机没有「可商用 + 有情绪 + 实时」的 TTS，因此**唱歌链路不能靠换 TTS 引擎解决**；说话仍走商业 API（MiMo），唱歌走 RVC（SVC）+ DiffSinger（SVS，后续）。

## 2. 需要 owner 提供的素材（清单，先等，不自己找）

### 2.1 五组情绪参考音（说话，不是唱歌）

**记录在前的两条事实**：五组里只有 `sweet_normal` 有一个合成 stub（`design_sweet_normal.wav`，不是真人素材，不能当交付物）；因此实际缺口是**四组全缺**（`tsundere_refuse` / `rage_spray` / `lazy_yawn` / `clumsy_panic`），加 `sweet_normal` 需用授权声源重录。

> 命名口径：item 5 的旧清单第五组写作 `happy_rice`（干饭开心）；owner 本轮工单写的是 `clumsy_panic`（心虚慌乱）。本文件按**工单口径**列 `clumsy_panic`；若 owner 两个都想要，就当第六组，验收时按六组算。**「按情绪切参考克隆」已判死不产品化**，这五条只作情绪对照与听感验收，不是切换克隆参考。

用途：补齐声线人格的五档情绪参考；**不用于按情绪切参考克隆**（该方法已在证据 §2.16.2 判死）。

**台词表（每条情绪一段固定台词，录 3–5 遍挑 2 条交付）**：

| 情绪键 | 固定台词 | 表演提示 | 目标时长 |
| --- | --- | --- | --- |
| `sweet_normal` | 今天海风很温柔，我在这里陪着你，慢慢说说话，好不好？ | 温柔日常，微笑，气声轻，句尾轻上扬 | ≈4.8 s |
| `tsundere_refuse` | 哼，才不是为了你才留下的，别自作多情，我只是刚好有空而已。 | 傲娇拒绝，先急后软，重音在「别自作多情」 | ≈4.9 s |
| `rage_spray` | 你再说一遍试试看？我警告你，别太过分了，真的会生气的！ | 愤怒喷人，爆破音清晰，音量抬升不削波 | ≈4.6 s |
| `lazy_yawn` | 唔……好困啊，让我再赖一会儿，就一小会儿，别吵我嘛…… | 慵懒哈欠，开头真哈欠/吸气，尾音拖长 | ≈5.2 s |
| `clumsy_panic` | 啊、那个……我不是故意的！我马上就收拾好，真的真的对不起！ | 心虚慌乱，语速偏快，带停顿与慌乱找补 | ≈4.5 s |

（前四条台词沿用 [O5-svs-svc-backend-research.md](./O5-svs-svc-backend-research.md) §3 已写死的试听文本，保持可比；`clumsy_panic` 为本轮新增。）

**录制规格**（沿用 O5 已定口径，owner 可改）：

- **格式**：WAV / **24 kHz / mono / 16-bit PCM**；不要 mp3，不做混响/压缩/过度降噪。
- **时长与电平**：每条 **5.0 s ± 0.3 s**；峰值约 **−3 dBFS** 不削波；前后各留 0.2 s 静音。
- **一致性**：同一个人、同一支麦、同一距离、同一房间、同一增益，**一次录完**；整组统一响度，不逐条标准化。
- **命名**：`<emotion>-<take>.wav`（例：`clumsy_panic-01.wav`），按情绪分目录。

**录制环境 checklist**（照着打勾即可）：

- [ ] 安静房间，听不出空调/风扇/冰箱底噪；手机静音、关窗。
- [ ] 同一支麦、同一距离（15–20 cm）、同一增益，全程不移动、不换位置。
- [ ] 不开任何美声/降噪/混响/压缩；系统录音软件直出 WAV。
- [ ] 每条录完回听一遍：不削波（波形不顶格）、不喷麦、没有口水音。
- [ ] 每组之间休息一下，避免越录越累导致音色漂移。

**授权声明模板**（每组素材附一份，签字/电子确认均可；儿童声音必须由监护人签署）：

### 2.2 SVC 训练干声（RVC）

| 项 | 建议 | 说明 |
| --- | --- | --- |
| 总时长 | **≥10 分钟可试，30 分钟以上更稳** | 纯人声、无伴奏、无混响 |
| 切片 | 3–10 秒/条，静音处切开 | 可由工具自动切，但需人工抽查 |
| 格式 | 44.1 / 48 kHz WAV，mono 或 stereo 均可（训练会重采样） | 不要 mp3，不要现场带混响的版本 |
| 内容 | 覆盖说话 + 唱歌（若目标是唱歌） | 唱歌部分要**清唱**，不要带伴奏 |
| 音高覆盖 | 至少覆盖目标音域 ±1 个八度 | 儿童声线要额外说明是否允许变调 |
| 授权 | 同 2.1，逐文件留档 | `.pth` 与素材绑定留档 |

### 2.3 不需要 owner 提供、我能先做的

- 点歌台 UI 骨架与「真实回执」状态机（`accepted → status → outcome`），引擎未就绪时明确显示「引擎未安装」，不伪造 demo 音频。

## 4. 未做与风险

- 未下载任何 SVC/SVS 权重；RVC 仓库只核了代码许可，未实测本机 M4 上的 RTF 与稳定性（阶段二第一件事）。
- RVC 官方底模权重带「仅供研究使用」条款、RMVPE 上游无 LICENSE → 商用路径必须自训底模 + 换 FCPE/CREPE（详见 O5 逐文件篇），这条比代码许可更容易被忽略。
- 儿童声线的合法素材是**硬阻塞**：没有监护人授权就不能用儿童录音；替代方案（成年授权声源 + 音高/共振峰调整）必须如实标注「合成儿童化」，不得宣称是真实儿童音色。
- DiffSinger 官方 OpenCpop 检查点与 OpenVPI 声码器权重非商用（数据 CC BY-NC-ND / 权重 CC BY-NC-SA）→ SVS 商用要先自训声库与声码器，周期远长于 SVC。
