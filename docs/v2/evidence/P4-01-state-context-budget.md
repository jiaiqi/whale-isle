# P4-01：状态上下文章节级预算

## 决策声明

采用按 `## 章节` 边界压缩的状态上下文构造，替换三处盲切 `slice(0, 4000)` / `slice(0, 3500)`；超出预算时保留全部章节标题并按优先级给每节分配字符，被压缩或省略的章节明确标注原字符数与可用只读工具，绝不静默截断半行。参考 BWF 的真实状态分段（基本状态/背包/箱子/出口/人物/作物/附近物体/文字地图/任务）与 feiyu-os 的「严禁可见记忆留存墓碑占位符」原则，自行实现。

不采用提高固定字符上限（无边界保证，仍会切半行）、不采用视觉或规则替代状态文本、不按目标改写成 if/else 玩法规程。预算只决定「给多少字符」，不决定「玩什么」。

验证：真实采样 5 点中 3 点超过 4000，其中 2 点正好把「任务」章节从中间切断；3500 的晨间提示多次切断「文字地图」。单测覆盖短原文原样返回、长原文每节标题保留、省略段带原长度与工具名、不出现半行、超长单节仍标注、并验证原有 planner 32 例与决策提示集成。
