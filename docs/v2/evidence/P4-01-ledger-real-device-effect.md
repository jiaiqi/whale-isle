## 与提示位置修正的关系

第一版把提示段排在「长期经验与主人记忆」之后，真机复核发现模型**仍在同一坐标重复 3 次**——说明排在长文之后会被稀释。修正在 `c738395`：

1. 提示段移到「失败与停滞记忆」**紧后面**、长期经验之前
2. 提示补齐可执行的下一步方向（站位不可达→换相邻可站坐标；门未开→先做别的事；物品不存在→先 `list_chests`；路线不通→改用中转地图）
3. 新增回归断言：提示段索引必须 > 失败记忆索引，且 < 长期经验索引

## 验证口径

- 数据来源：隔离存档「鲸屿两季_455475850」真实《星露谷》客户端 + SMAPI + BlindWhaleFarmer
- 采样：`scratch/two-season-out/trace-*.jsonl` 的 decision / receipt 行 + `progress.json` + 落盘账本文件
- 单次观察窗口：秋7 06:00 → 10:10（游戏时间），14 次决策
- 观测为**单日窗口**，多日持续效果仍需更长浸泡；但「同一坐标零重复」在单窗口内已可判定

## 仍未验证

- 该账本的长期收益（是否真能减少跨日重复的**总量**）需要数日对比数据
- 账本不会自动清理「已不可能再复现」的签名（例如箱子后来被清空），当条目长期无新增失败时是否有噪声，待观察
