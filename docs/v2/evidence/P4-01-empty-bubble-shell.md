# P4-01：空心气泡修复

## 决策声明

采用渲染层当前页文本回填与“不可容纳时不显示”两个最小改动，修复已读完后布局重算把正文清空、只剩外壳和心情徽标的空心气泡；沿用现有分页与真实 DOM 容量判据，不新增跨进程字段。不采用隐藏到下一次 `show` 才恢复的定时重试，因为会给同一气泡制造新的生命周期竞态。

范围限 `bubbles.ts` 与一条真实 Electron 回归；验收脚本另加真机空心采样（仅观测，不改变显示阈值）。若回归失败回退本切片；真实游戏内是否仍出现需下一保存点载入后观察，不以单测或 E2E 冒充真机解决。

## 原因

1. `renderLayout` 在字体加载完成、舞台尺寸或上下文变化时整表重算。原有逻辑以“已读前缀”作为续读起点，读完时剩余串为空，仍创建 presentation 并显示气泡外壳，正文被设为空串。
2. 空间不足以容纳一个字符时，代码清空正文并保留 shell，`readingBlocked` 只标注等待空间，看起来即空心气泡。

## 修改

- 剩余文本为空且属于同一条已读完文本时，保留当前页原文，标记 `readDone`，不重开分页。
- 不可容纳分支隐藏根节点，保留 `pageText`，不再露出空心壳。
- 新增 `apps/desktop-host/e2e/bubble-empty-shell.e2e.spec.ts`：1.4 字号长文本读到末页后强制重算，正文仍等于当前页并可见；26×14 极小舞台不出现空心壳。

## 验证

- 首次运行失败：极小舞台恢复后正文仍为空，暴露“空间恢复不会自动重来”的既有行为。已把断言收窄为“极小空间不得显示空心壳”，不虚构自动恢复能力。
- 修订后该 Electron 回归 **1/1 通过**，8.70s。
- 完整 `pnpm verify:gate` 待执行。
