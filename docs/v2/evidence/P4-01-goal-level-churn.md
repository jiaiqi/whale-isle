# P4-01：目标层折返——修好坐标层后暴露的下一层

## 发现过程

修好坐标层（同坐标不重试）后，秋9 真机暴露了**更深一层**的同源病：同一**目标**在地图间反复折返。

秋9 意图原文（模型自己在说「换法子」）：

```
D interact (13,7)  「哼，短裤就在那儿，这次从下面够过去」
D forage           「那短裤被灌木卡着走不过去，先在店里捡捡能捡的野货，换个法子。」
D move_to (13,18)  「走不到那个格子就换个近点的地方站稳了再伸手捡短裤。」
D move_to (12,7)   「从另一侧绕过去拿那条短裤，别在同一个坐标上死磕！」
D interact (13,15) 「短裤拿不到，先摸摸店里能碰的东西」
D dialogue         「先把玛妮的休息对话关掉，别卡着界面干瞪眼」
D travel_to Town   「玛妮今天关门，短裤进不去，先去镇上给哈维送榛子。」
```

**坐标层提示生效了**（「别在同一个坐标上死磕」是它自己说的）。但它随后在地图层折返：

```
AnimalShop → Town → AnimalShop → Town → AnimalShop → Town
```

`travelPingPong=7 / travelTotal=11`（11 次跨地图里 7 次是折返）。

## 根因

原折返提示只看最近 3 个目的地，且只有 `normal` 级：

```ts
if (back[0] === back[2] && back[0] !== back[1]) {
  normal.push(`最近在 ${back.join(' → ')} 之间来回：…`);
}
```

单轮折返「A→B→A」是正常的来回办事；但「A→B→A→B→A」是同一件事反复没办成。两者需要区分强度。

## 修复（`415b925`）

- 统计最近 5 次 `travel_to` 的折返轮数（`dests[i] === dests[i-2] && dests[i] !== dests[i-1]`）
- **≥2 轮升级为 `urgent`**，并点名「同一件事在这里反复没办成，先确认它到底缺什么（门没开/好感不够/东西不在），别再把往返当进度」
- 单轮维持原 `normal` 提示，不误升级

## 验证

- `state-hints.spec.ts` **23/23 通过**：新增「6 次 AnimalShop↔Town 折返 → urgent 并含『同一件事在这里反复没办成』」与「单轮折返不升级」两组断言
- `pnpm verify:gate` 8 过 / 0 跳过 / 0 待接线

## 同源病的分层总结

这几天修的所有缺陷是**同一个病的不同表现层次**，每修好一层，下一层才露出来：

| 层次 | 真机表现 | 修复提交 |
| --- | --- | --- |
| 字符层 | 零宽字符 → 气泡只有外壳无正文 | `353a3b5` |
| 参数层 | `levels: 0`、`accept: true` 无效参数 | `0fcd593`、`353a3b5` |
| 坐标层 | 同一坐标失败 3~11 次 | `3a27d6f`、`960da9c` |
| 界面层 | 书摊/电梯菜单重复打开 | `b131bc0` |
| 门槛层 | 好感门当场再试不会变 / 限时门该等 | `8325392`、`7c488d3` |
| 目标层 | 同一件事跨地图折返 ≥2 轮 | `415b925` |

## 仍未验证

- `415b925` 的真实效果需重载构建后观察（出问题时实例跑的是旧构建，`travelPingPong` 已到 7/11）
- 目标层还有个未解的问题：模型**知道**「短裤拿不到」，但没法把这条结论持久化成「今天不再试短裤」——跨日账本记的是动作签名，不是目标放弃。这可能是一层新的病。
