# 05 --- 角色人格、声音身份与表演系统

## 1. 目标

让 AI 不只是"LLM 输出文字 + TTS
朗读"，而是有稳定人格、情绪连续性、独立声音、说话风格、唱歌风格和身体表现的数字角色。

## 2. 四层角色状态

### 稳定人格

变化缓慢：好奇心、外向程度、幽默感、创造力、耐心、冒险倾向、社交意愿、表达习惯、价值偏好和边界。

### 长期偏好

由经历逐渐形成：喜欢的游戏、音乐、主题、创作风格，以及对不同人物和活动的偏好。偏好更新要保留来源和变化历史。

### 短期情绪

开心、兴奋、疲惫、失落、好奇、紧张等。情绪影响语气、动作和是否主动发言，但不能提升权限。

### 当前表现状态

`idle`、`listening`、`thinking`、`speaking`、`singing`、`dancing`、`gaming`、`reacting`、`resting`。

## 3. 声音身份 Voice Identity

每个角色有独立 Voice Profile： - 音色描述； - 参考音频或 Provider Voice
ID； - 语言和口音； - 音域； - 音高倾向； - 共鸣和气声； - 咬字； -
韵律； - 语速； - 情绪表现； - 唱歌风格； - 授权和来源记录。

声音身份要与 Provider 解耦。更换 TTS
服务后，通过参考音频、音色描述或专属模型尽量维持声音一致性。

不得未经授权克隆现实人物或歌手声音。

## 4. 说话风格

同一个音色可以有不同表达方式：日常聊天、开心、认真解释、游戏专注、直播主持、安慰、调侃、疲惫、惊讶。

建议将表达计划结构化：

``` ts
interface SpeechPerformancePlan {
  text: string;
  intent: string;
  emotion: string;
  intensity: number;
  pace: "slow" | "normal" | "fast";
  prosodyHint?: string;
  pauseHints?: number[];
  gestureIds: string[];
  expressionId?: string;
  interruptible: boolean;
}
```

## 5. 自然说话的关键

自然感来自： - 是否应该说； - 何时说； - 说多长； - 是否打断； -
是否延续上下文； - 是否记得以前说过的事； - 是否允许沉默； -
是否根据对方节奏调整。

角色应有"安静陪伴"能力，不要对每个事件都自动输出语音。

## 6. TTS 架构

Voice Runtime 统一处理： - 文本规范化； - 语音任务； - 流式生成； -
音频缓冲； - 播放队列； - 中断和取消； - 情绪参数； - 口型驱动数据； -
音频输出设备； - 延迟和质量监控。

候选技术需实测： - CosyVoice 系列； - MOSS-TTS； - 在线 TTS/实时语音
API； - 其他可商用且许可清晰的中文 TTS。

候选不等于批准依赖。必须测试中文自然度、音色一致性、流式首包延迟、并发能力、GPU
占用和许可。

## 7. 唱歌系统

普通 TTS 不等于唱歌。Sing Engine 分为：

### Singing Voice Synthesis

输入歌词、旋律/MIDI、节奏和角色声音风格，生成歌声。

### Singing Voice Conversion

输入已有演唱音频，转换成授权的角色声音。

还需要音域适配、旋律和节奏、发音和韵律、颤音、情绪、混音、伴奏、歌词时间轴和音画同步。

歌曲、伴奏、歌词和声音模型必须有相应授权。

## 8. Performance Engine

将 Agent 的表达意图转成面部表情、眼神、身体动作、桌宠动画、Live2D
参数、VRM BlendShape、游戏动作、舞台动作和口型。

动作优先级建议： 1. 安全/系统状态； 2. 当前交互或游戏关键动作； 3.
说话/唱歌口型； 4. 情绪动作； 5. Idle 动作。

同一时间冲突动作应有仲裁，避免眨眼、跳舞、说话和游戏动作互相覆盖。

## 9. 口型同步

第一阶段可从音频能量/音素时间戳驱动基础口型开始；后续支持更精确的
Viseme、Live2D 参数和 VRM
BlendShapes。口型、表情和声音使用统一时间基准。

## 10. 验收

-   更换模型后角色人格配置不丢失；
-   更换 TTS Provider 后仍能使用角色 Voice Profile；
-   语音可中断、排队和取消；
-   多个表现动作不会冲突；
-   角色在合适场景可以保持沉默；
-   唱歌和说话使用不同任务管线；
-   直播语音和桌面语音可选择不同输出设备；
-   每个声音资产都有来源和许可记录。
