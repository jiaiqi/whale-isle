# 06 --- AI 创作工坊与数字资产流水线

## 1. 产品定位

Creative Studio 不自己训练通用图片或 3D
生成模型。它是模型调用、创作编排、资产处理、质量验证、版本管理和授权管理工作台。

**模型负责生成；鲸屿负责把生成结果变成可用、可复用、可验证、可授权的角色资产。**

## 2. 图片生成

支持两种入口：

### A. 本地 Coding Agent 调度

例如用户本地 Codex CLI 或其他支持图像工具的 Agent。鲸屿把任务交给
Agent，由 Agent 使用其可用的图片生成能力、MCP 或 API。

注意：本地运行 CLI 不代表图片一定在本地生成。若 Agent 调用在线
API，仍然会产生在线调用和费用。

### B. 直接调用 Image Provider

由 Media Generation Gateway 直接调用图片模型
API，适合稳定生产、批量任务和可观测工作流。

不能假设每个 Coding Agent
都具备生图能力。连接时要探测工具能力；不支持时明确标记。

## 3. 3D 生成

优先调用 3D 生成大模型，而不是把 Blender 当作生成引擎。

候选方向： - Hunyuan3D 系列； - 其他支持 text/image/multi-view-to-3D
的模型； - 后续可接入本地部署或云端 API。

3D
模型生成后仍需后处理：网格质量检查、法线、UV、材质、面数优化、骨骼、面部
BlendShapes、VRM 兼容和动画测试。

Blender
定位为自动化后处理、绑定、检查、导出和人工精修工具，而非主生成器。

## 4. 角色一致性

每个角色维护 Character Bible： - 正面/侧面/背面参考； -
发型、眼睛、配色、服装、身体比例； - 标志性配件； - 表情规范； -
风格约束； - 禁止改变的特征。

生成任务必须引用 Character Bible
和已批准参考图。新结果进入候选区，不自动覆盖已发布资产。

## 5. 五个工作室

-   **Character Design
    Studio**：角色设定、立绘、三视图、服装、表情、配色和参考图。
-   **2D Asset Studio**：透明 PNG、桌宠帧动画、Sprite
    Sheet、游戏像素人物、肖像、Live2D 分层图。
-   **3D Asset Studio**：3D 网格、材质、UV、骨骼、面部表情、VRM 导出。
-   **Animation
    Studio**：待机、行走、跳跃、说话、唱歌、舞蹈、表情和动作时间轴。
-   **Scene & Asset
    Studio**：舞台、背景、道具、特效、UI、游戏物品和直播素材。

## 6. 游戏像素素材流水线

1.  读取目标游戏资产规格；
2.  从 Character Bible 生成像素风格参考；
3.  生成角色各方向基础图；
4.  生成待机/行走/动作帧；
5.  对齐像素网格；
6.  检查帧尺寸和透明边界；
7.  处理调色板；
8.  生成 Sprite Sheet；
9.  生成游戏 Mod 所需 manifest；
10. 在游戏测试环境验证；
11. 通过后发布资产包。

AI 生成结果必须经过自动质量检查和必要的人工预览。

## 7. Live2D 与 VRM

Live2D：分层素材、头发/眼睛/嘴部/身体分层、参数命名、Rig、动作、表情和口型。

VRM：网格、材质、Humanoid 骨骼、BlendShapes、视线、物理、表情、动画和
VRM 版本兼容。

生成一个漂亮模型不代表它已经具备可动画能力。

## 8. Asset Pipeline

``` mermaid
flowchart LR
  BRIEF[Character Brief] --> GEN[Model Provider]
  GEN --> CANDIDATE[Candidate Assets]
  CANDIDATE --> POST[Post Processing]
  POST --> QA[Automated QA]
  QA --> REVIEW[Preview / Review]
  REVIEW --> LICENSE[Provenance & License Gate]
  LICENSE --> PUBLISH[Versioned Asset Pack]
  PUBLISH --> RUNTIME[Desktop / Game / Stage]
```

资产状态：
`draft`、`generating`、`candidate`、`processing`、`validation_failed`、`review_required`、`approved`、`published`、`deprecated`、`restricted`。

## 9. 资产来源与许可证

每个资产记录来源、作者、仓库/URL、许可证、商业使用、直播使用、再分发权限、模型和生成服务、输入参考素材、生成时间、Hash、审核记录。

AI
生成不自动等于拥有完整商业使用权。模型、服务、输入图片和第三方资产都可能带有限制。

## 10. 第三方素材策略

此前仓库文档记录过 CrossPet、dsh-pet
等素材存在非商业或署名/相同方式共享等限制。必须逐素材核对当前 LICENSE
和授权范围，不能仅凭源代码许可证判断素材能否用于直播或商业发行。

建议分为： - Development/Test Asset Pack； - Personal Use Asset Pack； -
Commercial/Release Asset Pack。

商业/直播发布包只允许通过授权门禁的素材。

## 11. 候选项目

-   ComfyUI：可作为可选生成工作流服务；若捆绑、修改或分发需评估 GPL
    义务。
-   Blender：3D 后处理和自动化工具。
-   VRM Add-on for Blender：VRM 导入导出候选，检查代码与分发许可。
-   Pixel art 工具：可研究 Pixelorama、Aseprite
    文件格式和其他项目；任何特定 AI Pixel Studio
    项目必须先验证仓库、维护情况和许可证。
-   Hunyuan3D：3D 生成候选，逐模型版本核对许可、商用条件和部署要求。

## 12. 验收

-   同一角色不同形态能保持主要视觉特征；
-   Sprite Sheet 尺寸、帧数、方向和锚点可自动验证；
-   3D 模型有可检查的网格、骨骼和表情；
-   资产有版本、Hash 和来源；
-   未通过授权门禁的素材不能进入商业发布包；
-   生成失败、处理失败和审核失败均可追踪；
-   角色更新可以回滚到上一版资产。
