# 03 --- 领域模型与数据契约

## 1. 核心概念必须分开

-   **Character**：用户认知中的角色身份，例如"小莓"。
-   **Agent Runtime**：实际运行的思考、规划和工具调用进程。
-   **Model Provider**：模型服务，例如 LLM、图片模型或语音模型。
-   **Harness**：承载 Agent 执行的外部运行框架。
-   **Embodiment**：角色在某个场景中的身体/表现形态。
-   **Device**：运行桌宠、游戏、浏览器或 Agent 的电脑。
-   **Account**：角色绑定的外部平台账号。
-   **Asset**：形象、声音、动作、舞台和游戏素材。
-   **Memory**：角色经历、知识、关系和偏好记录。

更换模型不应创建新 Character；更换桌宠外观不应创建新 Agent；同一
Character 可有多个 Embodiment。

## 2. Character

``` ts
interface Character {
  characterId: string;
  displayName: string;
  description?: string;
  personaProfileId: string;
  voiceProfileId?: string;
  assetSetId: string;
  lifecycle: "active" | "archived";
  createdAt: string;
  updatedAt: string;
}
```

## 3. Agent Runtime

``` ts
interface AgentRuntime {
  agentRuntimeId: string;
  characterId: string;
  runtimeMode: "primary" | "worker" | "passive";
  harnessProviderId: string;
  modelProfileId: string;
  memoryNamespace: string;
  status: "stopped" | "starting" | "running" | "paused" | "failed";
  deviceId?: string;
}
```

第一阶段只有一个 `primary` Runtime。其他桌宠可以是
`passive`，不创建完整自主循环。

## 4. Persona Profile

``` ts
interface PersonaProfile {
  personaProfileId: string;
  characterId: string;
  stableTraits: Record<string, number>;
  values: string[];
  preferences: {
    topics?: string[];
    music?: string[];
    games?: string[];
    communicationStyle?: string[];
  };
  behaviorRules: string[];
  boundaries: string[];
  version: number;
}
```

人格参数是控制角色表达和行为的可解释配置，不是心理测量。

## 5. Mood State

``` ts
interface MoodState {
```

情绪是短期状态，不应覆盖稳定人格，也不能提升工具权限。

## 9. Account Binding

``` ts
interface SocialAccountBinding {
  accountId: string;
```

## 10. Device 与 Lease

``` ts
interface DeviceNode {
  deviceId: string;
  name: string;
  os: string;
  capabilities: string[];
  appVersion: string;
  lastSeenAt: string;
}

interface ComputerUseLease {
  deviceId: string;
  holderAgentRuntimeId: string;
  grantedAt: string;
  expiresAt: string;
  status: "active" | "paused" | "revoked";
}
```

同一台设备同一时间只有一个 Agent
获得键鼠/前台桌面控制权。用户输入优先级最高。

## 11. Memory Record

``` ts
interface MemoryRecord {
  memoryId: string;
  characterId: string;
  memoryType: "working" | "episodic" | "semantic" | "relational" | "self";
  summary: string;
  entities: string[];
  sourceEventIds: string[];
  confidence: number;
  salience: number;
  createdAt: string;
  lastRecalledAt?: string;
  retentionPolicy: string;
  userPinned: boolean;
}
```

必须保留来源和置信度。模型推测不得伪装成事实。

## 12. Plugin / Skill / Tool

-   Plugin：安装和生命周期单位；
-   Skill：教 Agent 如何完成任务的知识包；
-   MCP Server：对外暴露工具/资源/提示；
-   Tool：可执行操作；
-   Harness Adapter：连接外部 Agent 执行环境。

这些概念不能混为一谈。

## 13. ID 规则

ID 使用稳定 UUID/ULID 或项目统一规范；外部平台 ID
保留外部命名空间；不使用显示名称作为主键；跨模块引用带版本或兼容策略；删除角色时先处理关联账号、记忆、资产和备份策略。

## V2.1 增补：游戏目标、知识和控制权数据

Game Runtime 需要补充以下领域对象：`GameGoal`（自主/用户/共同目标）、`GameKnowledgeItem`（带来源、版本、适用条件、置信度和验证状态的攻略知识）、`GameExperience`（行动和实际结果）、`GameControlMode`（自主/协作/指令/手动接管）、`GameCommand`（用户直接指令）和 `ControlLease`（有期限的控制权租约）。

建议和接口定义见 `17-自主游戏智能与人机共玩系统.md`。这些对象应进入版本化共享协议，不能只保存在 Prompt 文本中。
