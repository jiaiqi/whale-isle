## 3. 五情绪映射（与语音中心五档一一对应）

音高偏移取自语音中心既有的 `MCODE_MODES`（`apps/desktop-host/src/main/voice-host.ts`），
风格指令与标签取自语音包常量 `MIMO_EMOTION_STYLE_HINTS` / `MIMO_EMOTION_STYLE_TAGS`
（`packages/voice-runtime/src/providers.ts`）。**改一处必须同步另一处**。

| 档位 id | 中文名 | 音高偏移 | 自然语言风格指令（user 侧） | 助手前缀标签 | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| `daily` | 软萌小仆 | +0 半音 | **情绪外放夸张，甜得发腻，语调起伏大，尾音拖长，带撒娇的鼻音**（撒娇 B 级） | `(Sweet)` | 日常应答、撒娇、递东西 |
| `bright` | 俏皮上扬 | +4 半音 | **情绪外放夸张，语调起伏大，重音明显，尾音拖长上扬，像在台上表演**（调皮 B 级） | `(Playful)` | 撒娇、玩梗、被夸之后 |
| `tsundere` | 傲娇炸毛 | +12 半音 | **情绪外放夸张，语气冲，咬字重，尾音先压下再挑起，明显不服气**（傲娇 B 级） | `(Tsundere)` | 被叫"大肥鱼"、被摸头、被拆穿 |
| `sleepy` | 慵懒气声 | −4 半音 | 慵懒困倦，气声偏多，语速偏慢 | `(Sleepy)` | 内心戏、深夜、刚被叫醒 |
| `surprised` | 惊喜元气 | +6 半音 | 惊喜元气，语气上扬，节奏轻快 | `(Excited)` | 收到礼物、开饭、意外收获 |

声音工坊的五情绪锚点是同一套情绪的别名，共用同一份指令与标签：
`sweet_normal → daily`、`tsundere_refuse → tsundere`、`rage_spray → tsundere`（音量更大）、
`lazy_yawn → sleepy`、`clumsy_panic → surprised`（心虚版，指令单独写为"心虚慌乱，语速偏快，带一点不确定"）。

### 3.1 每种控制手段怎么用

0. **不采用「按档情绪参考音频 + 按档克隆」**：实测直接切情绪参考会把角色音色一起换掉
   （五条情绪参考彼此余弦只有 0.5158），两段式保人但情绪效果掉回对照水平（证据文档 §2.16.2）。
   五档情绪仍只走下面这几种「指令 + 标签」手段。
1. **user 侧自然语言风格指令**（推荐主用）：官方口径对**所有 MiMo 模型**有效，且不会被念出来。
   VoiceDesign 里它跟在音色描述后面（`…；风格：傲娇嘴硬…`），其它模式单独作为 `user` 消息。
   未知情绪**不注入**，宁可退回默认语气，也不编造一段风格。
2. **助手前缀标签**：把 `(Tsundere)` 放在要说的正文最前面。官方接受半角 `()`、全角 `（）`、`[]` 三种写法，
   本仓库统一半角，避免同一句里混排。标签必须和风格指令同向，别一边写"慵懒"一边打 `(Excited)`。
3. **正文内联音频标签**：可以出现在正文任意位置，例如
   `主人……(sighs deeply) 本鱼真的没有偷懒。(pauses for a moment) 只是刚好在思考人生。`
   常用：`(sighs deeply)`、`(cough)`、`(pauses for a moment)`。
   规则：**一句最多一个**，且只在情绪转折处用；连续堆叠会挤掉正常语调，听感变成"音效串烧"。
4. **唱歌**：只有 `mimo-v2.5-tts` 支持，用正文前缀 `(唱歌)` / `(sing)` / `(singing)` 触发，
   本仓库统一用 `(唱歌)`；由 `styleMode: 'singing'` 自动加，不要在台词里手写。
5. **`optimize_text_preview`**：仅 VoiceDesign，开了以后只按音色描述做预览、可以不传正文。
   用来"只听音色不听话术"的调音阶段，正式播报不要开。

### 3.2 表演强度 A / B / C（默认 B，2026-11-27 接线）

owner 判「音色对，表演要重做，三档都要重做，主要是情绪太弱」后做了强度阶梯实验（证据 §2.18），
**B 级按预注册判据成立**（Δ 时长 1.36s ≥ 2σ 0.83、Δ RMS 4.45dB ≥ 2σ 2.74），现在接线进产品：

- **B（默认）**：§3 表里 `daily` / `bright` / `tsundere` 三档的指令就是 B 级原文，源码在
  `MIMO_PERFORMANCE_B_HINTS`（`packages/voice-runtime/src/providers.ts`），`resolveMimoEmotionHint()` 默认取它。
- **A（提级对照）**：旧指令 + 「，更外放」（`MIMO_PERFORMANCE_A_SUFFIX`）。实测 RMS 档间差只有 0.56dB，**没拉开**，
  保留在工坊里做对照，不做产品默认。
- **C（副语言）**：B + 「，可以笑出声、哼气、叹气、吸气」（`MIMO_PERFORMANCE_C_SUFFIX`），配合正文内联标签。
  实测能把时长再拉长 2.3–2.9s、F0 档间差拉到 51.0Hz，但档内方差同步暴涨（判据不过）。
  C 级用到的 `(giggles)` / `(laughs)` / `(hmph)` / `(inhales)` **标签是否真的渲染仍是间接判断（看时长），未经听感验证**，
  所以只在工坊「试戴强度 C」里做实验，**不写进任何产品档位**。
- **`sleepy` / `surprised` 不受影响**：强度阶梯只对调皮 / 傲娇 / 撒娇三档做过实验，没有数据的档位不编造模板。

**一条已判死的路**：**音高不能用来区分情绪**。同一批实验里三档的 F0 中位完全重合（B 级 348.1 / 347.8 / 347.8Hz），
A 级 Δ F0 19.6Hz、C 级 51.0Hz 全是标签带出来的、且档内 σ 30–42Hz。
在 MiMo 的指令层靠「写音高」区分情绪**不成立**，能拉开的是**响度、语速、副语言**。

> 诚实口径：B 级是**按客观量**接线，owner 还没有逐条试听这 18 条；听感不合适就在音色工坊里换 A/C 或改指令，
> 不要反过来改判据或挑好结果重跑。

## 4. 实测与未实测（2026-11-27 更新，证据见 [mimo-tts-candidate-integration.md](./evidence/mimo-tts-candidate-integration.md) §2.5）

已实测（单次迹象，可复现）：

- `api-key` 与 `Bearer` 两种认证头**都已实测通**（各自一次 200 + 音频）。
- 五种风格控制（baseline / daily / bright / tsundere / sleepy / surprised）在同一句话上**确实产生了可测的差异**：
  时长 3.52 → 4.96s（+41%），F0 中位 216.2–255.3 Hz（慵懒最低、惊喜最高）。这是**迹象不是听感结论**，
  听感留给 owner；稳定性（多次重复）未测。
- 正文内联标签（`(sighs deeply)` + `(pauses for a moment)`）一次成功，音频 7.04s。
- VoiceDesign 按第 2 节的音色描述一次成功（1972ms / 5.6s）。

已定稿的漂移结论（实测，证据 §2.8）：

- **VoiceDesign 同一描述连跑 10 次，说话人余弦最小 0.4145**——漂移是实的，不能当角色固定声线。
- 推荐路径：**VoiceDesign 出候选 → 人工挑一条 → 用自产音频走 VoiceClone 锁死**；
  参考音频必须是自产或已获授权的录音，不碰他人声音。

声线定稿后的实测（2026-11-27，证据见 [mimo-tts-candidate-integration.md](./evidence/mimo-tts-candidate-integration.md) §2.14 / §2.17）：

- **clone 锁定（07 甜脆·元气，最终定稿）**：随包参考音频同一句 ×10，10/10 成功；
  说话人余弦均值 **0.9059** / 最小 **0.8814** / σ **0.0148**；克隆输出 vs 参考音频均值 0.9086 / 最小 0.8824。
  与成人基线并列：旧 07 黏糊·调皮 0.8373 / **0.7723** / 0.0245，12 憨憨 0.8912 / 0.8340，08 0.8705 / 0.7552，02 0.8275 / 0.7189。
  **儿童声线并没有把一致性拖低**（最低值反而比成人基线高 0.109），所以这条不需要「拿成人门槛硬套」的免责。
  **仍然只证明「对这条参考音频的一致性」**，且克隆句与参考句是同一句（协议一贯口径，会抬高一致性），未做听感盲测。
- **三种表演（调皮 / 傲娇 / 撒娇，同一句 ×3）**：用产品真实手段（五档风格指令 + 前缀标签 + 一个内联标签），
  映射到 `bright` / `tsundere` / `daily`，另跑中性对照。客观量上**只有时长分开**（调皮 5.17s vs 傲娇 4.16s，约 3σ），
  F0 档间极差 12.9Hz 而档内 σ 42–78Hz、RMS 档间 1.06dB 而 σ 1.2–3.5dB——**基频和响度没拉开**，
  听感判定留给 owner（产物 `artifacts/tts-ab/perform-07-tiancui/`）。
- **强度阶梯 A/B/C（18 条，判据先注册后跑）**：B 级成立（Δ 时长 1.36 vs 2σ 0.83、Δ RMS 4.45 vs 2σ 2.74），
  已接线成三档情绪的默认指令（§3.2）；A 不成立、C 时长与 F0 拉开但方差暴涨。
  **基频三档始终没分开**（B 级 348.1 / 347.8 / 347.8Hz）→ 「音高区分情绪」在 MiMo 指令层不成立。
  产物 `artifacts/tts-ab/perform2-07-tiancui/`，证据 §2.18。
- **出厂 07 的一致性有批次波动**（2026-11-27 工坊实测，证据 §2.19.3）：同一随包参考、同一句 ×10 跑三次，
  均值 0.9059 / 0.8632 / 0.8795、最小 0.8814 / 0.7296 / 0.7876 → 结论会在「锁得稳」与「偶尔飘」之间翻面。
  §2.17 那个 0.9059 / 0.8814 是**其中一次**，引用时必须带上这个波动区间，不能当成固定指标。
- **「按档情绪参考 + 按档克隆」已判不产品化**：直接切情绪参考等于换人（五条参考彼此余弦只有 0.5158），
  两段式保人但情绪效果掉回对照水平（F0 档间极差 26.75Hz，韵律距离判据未过）。数字见证据文档 §2.16.2。
- **废弃口径**：旧 07 的五档情绪 ×3（时长 5.12–5.49s、F0 284.3–297.1Hz）**当时一条风格指令都没发出去**——
  bench 自己抄的情绪表缺语音中心的键，请求体是空 user 消息（§2.16.0）。那组「没拉开」的数字**作废**，不能引用。

仍未实测（不许写成已支持）：

- 唱歌听感；内置音色（`mimo-tts`）上的五档情绪分布；clone 声线上五档情绪的主观听感判定；
  VoiceClone 与「某个真人/目标音色」的相似度（需合法目标参考音频）。
- MiMo 流式（`pcm16`）**未实现**，`supportsStreaming` 固定 `false`。
- OpenRouter Gemini 3.8 Flash TTS 的情绪控制方式官方没有说法，一律按"未验证"处理；要试就在 bench 单开实验组。
- 音高偏移是 mcode 链路的参数，**不能**直接套到 MiMo / OpenRouter 上：它们的 API 没有 pitch 字段。
  商业 TTS 下只能靠风格指令与标签间接影响音高。
