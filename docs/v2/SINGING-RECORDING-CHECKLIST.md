## 2. 每组录几条

- **每组录 3–5 遍，挑最好的 2 条交付**（扫描器会提示同组重复，两份里留一份主用即可）。
- **单条 5.0 s ± 0.3 s**（即 4.7–5.3 s）；台词念完不要拖长空白。
- 五组之间休息一下，避免越录越累、音色漂移。

## 3. 格式与电平（照做，不要后期）

| 项 | 要求 |
| --- | --- |
| 容器/编码 | **WAV（PCM）**，不要 mp3、m4a |
| 采样率 | **24 kHz** |
| 位深 | **16-bit** |
| 声道 | **单声道（mono）** |
| 峰值 | 约 **−3 dBFS**，**不削波**（波形不顶格） |
| 头尾静音 | 前后各留 **0.2 s** 静音 |
| 后处理 | **不开**降噪、混响、压缩、美声、均衡；录音软件直出 |

**环境**：安静房间，听不出空调/风扇/冰箱底噪；手机静音、关窗；**同一支麦、同一距离 15–20 cm、同一增益，六组一次录完**，中途不换位置。

每条录完回听一遍：不削波、不喷麦、没有明显口水音。不合格就重录，不要靠软件修。

## 4. 放哪里、怎么命名

素材根目录（面板上会显示并可直接复制）：

```text
<userData>/singing/materials/
```

macOS 开发态一般是：

```text
~/Library/Application Support/Whale Isle/singing/materials/
```

**以中控台「演唱素材」面板显示的路径为准**（不同安装方式可能不同）。

目录结构（推荐：按情绪分目录，扫描器认目录名，也认文件名前缀）：

```text
singing/materials/
├── consent.json                  # 授权声明（必填，见第 5 节）
├── sweet_normal/
│   ├── sweet_normal-01.wav
│   └── sweet_normal-02.wav
├── tsundere_refuse/
│   ├── tsundere_refuse-01.wav
│   └── tsundere_refuse-02.wav
├── rage_spray/
├── lazy_yawn/
├── clumsy_panic/
├── happy_rice/
└── training/                     # SVC 训练干声（见第 6 节）
    ├── train-01.wav
    └── ...
```

命名规则：`<情绪键>-<两位序号>.wav`；情绪键必须是上表六个之一（拼错会被标成"未分组"）。

## 5. 授权声明（必须有，否则扫描器逐个文件标「缺授权」）

在素材根目录新建 `consent.json`，内容照抄改成你的信息：

```json
{
  "identityId": "xiaojing-singing",
  "displayName": "小鲸",
  "source": "owner_authorized_recording",
  "consentScopes": ["training", "synthesis", "commercial_livestream", "redistribution"],
  "consentEvidenceRef": "CONSENT-2026-001",
  "minorVoice": false,
  "guardianConsent": false,
  "weightLicense": "unknown",
  "svcModelPath": "",
  "svcIndexPath": "",
  "svsVoicebankPath": ""
}
```

- `consentEvidenceRef` 只填**声明编号/文件名**，不要放身份证号等个人信息；签字的纸质/PDF 自己留存。
- 儿童声音：`minorVoice: true` 且 `guardianConsent: true`，并附监护人签署的授权声明；缺一项扫描器直接阻断。
- 商用直播：`consentScopes` 必须含 `commercial_livestream`；权重许可在自训完成前保持 `unknown`（不要填 `commercial_ok` 骗过判定）。

授权声明模板（打印签字或电子确认均可）：

```text
声音素材授权声明

授权人：____________（身份证/护照后四位：______）
声音主体：____________（若与授权人不同请填写；未成年人的声音必须由监护人签署）
与声音主体关系：本人 / 监护人 / 其他（______）

授权范围（勾选）：
[ ] 用于训练/微调本项目的语音与歌声模型
[ ] 用于生成合成语音并在本项目产品中使用
[ ] 允许商业化使用（含直播）
[ ] 允许随产品再分发训练产物（模型权重）
[ ] 仅限内部评估，不得商用、不得再分发

地域：____________    期限：____________（或「永久」）
署名要求：无需署名 / 需署名（写法：____________）

我确认以上声音为我本人（或我监护对象）的声音，未使用任何第三方录音；
授权人可在书面通知后要求停止使用并删除相关素材与由其训练的模型。

授权人签名：____________    日期：____________
```

> 声明编号填进 `consentEvidenceRef`，原件自己保管，**不要**放进素材目录。

## 6. SVC 训练干声（单独一节）

放在 `training/` 子目录，文件名 `train-NN.wav`：

| 项 | 要求 |
| --- | --- |
| 总时长 | **≥10 分钟可试；30 分钟以上更稳** |
| 切片 | **3–10 秒/条**，在静音处切开 |
| 格式 | 44.1 kHz 或 48 kHz WAV；mono/stereo 均可（训练会重采样） |
| 内容 | 纯人声、**无伴奏、无混响**；说话 + 清唱都要有（目标是唱歌就多录清唱） |
| 音高覆盖 | 至少覆盖目标音域上下各一个八度 |
| 授权 | 同一份授权声明覆盖；`.pth` 与素材一一绑定留档（谁的声音、授权范围、训练日期） |

> 训练干声和情绪参考音可以同一天录，但**不要**把带伴奏的成品歌丢进 `training/`——那会污染训练。

## 7. 录完之后

1. 文件按第 4 节放好、`consent.json` 填好。
2. 中控台 →「点歌台」→「演唱素材」→ 点「重新扫描」。
3. 面板会给出三样东西：
   - **六组覆盖**：哪组齐了、哪组缺；
   - **逐文件问题**：采样率/位深/时长/峰值/静音/授权；
   - **两行结论**：`ready`（现在能不能唱）与 `commercialReady`（能不能商用/开播）。
4. 有 blocker 就按提示重录；扫描器不会替你"默认通过"。

**仍然缺的最后一块**：可追溯的 RVC `.pth`（自训或书面授权）。在它到位之前，`ready` 会一直是 false，这是故意的。
