插件与沙箱 · Plugin Sandboxmanifest 白名单 · 隔离四策略
plugin.manifest · 示例 whale.timer-ring · v0.3.1
{ "id": "whale.timer-ring", "version": "0.3.1", "permissions": ["character.read", "asset.read"], "capabilities": ["stage.overlay.render"], "sandbox": { "process": "isolated", "fs": "ro:/assets", "net": "deny" }, "rollback": { "prev": "0.3.0", "snapshot": "snap_9c41" } }

permissions 是申请而不是授予——Broker 按 capability 台账逐项校验，未声明一律拒绝；net: deny 意味着插件无法外联回传。
