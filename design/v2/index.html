WHALE ISLE V2 · UI/UX DESIGN SYSTEM

潮汐 Tide v5

鲸屿 V2 的设计母题是「深海屿光」：角色是深海中会发光的数字生命体，控制台是守望它的灯塔。 本套系统承接 v4「曜石」的玻璃材质与 Apple 三原则，把色温转向深海墨蓝，以 鲸光青 为主色、 极光渐变为品牌时刻，并新增声呐环、回执芯片、许可徽章、控制权 HUD 四个签名组件—— 分别回应蓝图对表现状态、真实回执、素材授权、用户控制权的四个硬要求。

设计原则 · 六条铁律来自蓝图 §README 8 原则 × PRD 体验原则

一个 AI，多种身体

Character Identity 是唯一恒星，化身只是投影。界面永远显示当前角色与其全部化身的一致性状态，换模型、换皮肤不产生新角色。

决策透明可解释

每一个自主动作都带「目标 · 动作 · 一句话理由 · 置信度 · 证据来源」。不要求用户看懂全部推理，但任何时候都能追问“为什么”。

控制权最高优先

停止 / 接管入口永远在视线内。四档控制模式（自主·协作·指令·接管）用同一套 HUD 表达，用户键鼠输入永远压过 AI。

回执不撒谎

COMPLETED / UNCERTAIN / FAILED 三色回执芯片贯穿游戏、语音、资产全链路。「发出命令」与「任务完成」在视觉上永远不同。

授权显性化

许可徽章（MIT / Apache / CC BY-NC-SA / 无许可证）出现在每个素材、每个账号、每条攻略知识上；P0–P5 权限阶梯可见可调。

本地优先 · 安静陪伴

凭证入系统钥匙串、费用与预算常驻侧栏、勿扰一键可达。角色可以选择沉默——安静是一种被设计的状态，不是缺失。

声呐环 Sonar

GAMING · 星露谷
RESTING · 静默

回应《05 表演系统》九态表现状态。脉冲环向外扩散表达"活着"；颜色随表现状态切换（青=活跃/琥珀=休息/紫=表演/红=告警）。总览、桌宠、直播页复用同一语义。

回执芯片 Receipt

COMPLETED · 0.42sIN_PROGRESS
UNCERTAIN · 重试2/3FAILED · 卡石头

回应《07 游戏化身》与仓库铁律「真实执行回执」。任何自动化动作都以三色回执收口，UNCERTAIN 必须带重试计数，FAILED 必须带原因。严禁把绿色之外的任何状态画成完成。

MITAPACHE-2.0CC BY-NC-SA 4.0UNLICENSED

保留

玻璃材质七层、发丝线、统一 Shell 栅格、lucide 图标体系、深浅双主题机制、⌘K 命令面板、reduced-motion 适配——全部原样承继。

重调

主色从系统蓝 #0A84FF 转向鲸光青 #3EE0CD；背景从纯黑转向深海分层墨蓝；语义色统一饱和度曲线；极光渐变取代零散的多彩光斑。

新增

声呐环、回执芯片、许可徽章、控制权 HUD、能力矩阵、决策循环、化身星座图——把蓝图特有的领域概念（回执/授权/控制权）变成一等组件。

重组

导航从 20+ 插件平铺重组为「六世界十页面」：现有 chat/memory/voice/pet/providers/plugins… 面板全部有新家，映射表见 SPEC 附录。
